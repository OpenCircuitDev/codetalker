Conventions
  • Phone screenshots: 280×580 portrait or scaled-to-fit. Strip notch via crop. Save as android.<path>.png.
  • Glasses captures: XREAL Air 2 Pro outputs DisplayPort. Best path is OBS recording the Beam Pro's mirrored output, screenshot a frame, save as xreal.<path>.png at 16:9.
  • Status badge: auto-rendered. Set data-status="mockup" for placeholders, data-status="screenshot" when real. Banner totals update automatically.
  • Filter button: "show all / show mockups only / show screenshots only" cycles through filter states — useful when QA-ing only the un-photographed sections.
  • Print/PDF: Ctrl+P → Save as PDF. Print stylesheet hides nav, switches palette to print-friendly, expands cards.
  • Anchor links: every mockup has a stable id like #mockup-android.pairing.choose. Link to those in CHANGELOG, plans, and PR descriptions; the URL never changes even when the mockup becomes a screenshot.
